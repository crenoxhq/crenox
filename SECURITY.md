# Security Policy

## Supported Versions

Crenox maintains active security updates for the current major release series.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | Yes                |
| < 2.0   | No                 |

## Reporting a Vulnerability

The Crenox engineering team takes the security of our secret detection engine seriously. If you identify a potential security vulnerability, do not open a public GitHub issue.

### Private Reporting Channel

Submit vulnerability reports privately through GitHub Security Advisories:

https://github.com/crenoxhq/crenox/security/advisories/new

All security reports are reviewed confidentially by the core maintainers.

### Information to Include

To assist in validation and triage, please provide:
- A clear description of the vulnerability and its potential impact.
- Reproducible steps, proof-of-concept inputs, or minimal target files.
- The specific Crenox version, operating system, and hardware architecture.

### Response Timelines

- **Initial Response:** Within 48 hours of receipt.
- **Assessment & Status:** Updates provided within 5 business days.
- **Remediation & Release:** Security patches are prioritized and released following coordinated disclosure.
