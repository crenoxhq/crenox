System Topology

Two Statically Compiled Binaries

crenox-master Central Controller

Fleet Governance & Audit Repository

Deployed on customer internal private servers. Acts as the central policy distribution authority, seat quota manager, and persistent audit storage.

  • Embedded administrative web console without third-party CDN or asset calls
  • Centralized policy signing and distribution of organization YAML detection rules
  • Append-only immutable audit ledger recording blocked commits and integrity alerts
  • Enterprise authentication via OIDC and perimeter reverse proxy headers
  • Binds strictly to configured private internal network interfaces
Central fleet console — posture, events and coverage at a glance
crenox-agent Workstation Agent

Local Pre-Commit Interception Engine

Installed across developer workstations. Evaluates staged Git buffers, paths, and filenames directly in memory prior to commit completion.

  • Evaluates staged buffers in memory prior to commit finalization
  • Fail-closed interception halting commits upon detection (Exit Code 1)
  • Monitors Git hook configurations and detects unauthorized bypasses
  • Supervised developer Just-In-Time (JIT) exemption review workflow
  • History redaction utility to rewrite past commits (crenox purge)
The agent stops the commit before it lands — value masked, remediation printed
